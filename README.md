# 🏋️‍♂️ نظام التنبيه الذكي للوجبات والتمارين المنزلية (Smart Fitness & Meal Notifier)

نظام متكامل، آلي، وجاهز للنشر الفوري مصمم خصيصاً وفقاً لجدولك اليومي وتوقيت القاهرة (`Africa/Cairo` - UTC+2). يقوم النظام بحساب **مهلة الإشعار المسبقة (Lead Time)** بدقة قبل مواعيد وجباتك الخمس وتمارينك ومكملاتك اليومية، وإرسال تنبيهات تفاعلية عبر **Telegram Bot** (ومدعوم أيضاً بمحول اختياري لـ **WhatsApp** عبر CallMeBot)، بالإضافة إلى **لوحة تحكم ويب عصرية (Web Dashboard)** للتحكم بضغطة زر واحدة.

---

## 🌟 1. منطق التنبيه وحساب المهلة المسبقة (Lead-Time Engine)

تمت برمجة النظام بحيث **لا يرسل التنبيه في نفس موعد الوجبة أو التمرين**، بل يتم طرح وقت المهلة المسبقة تلقائياً بناءً على فئة الحدث:

| الفئة (`Category`) | المهلة المسبقة | موعد الحدث الفعلي | 🔔 وقت إطلاق التنبيه | تفاصيل الحدث والغرض من المهلة |
| :--- | :---: | :---: | :---: | :--- |
| **`LIGHT_MEAL_OR_SNACK`** | **15 دقيقة** | 08:00 صباحاً | **07:45 صباحاً** | 🍳 **الفطار:** الدايجستين + فيتامين د + 3 بيضات + بطاطس وعيش + جبنة رودس وزيت زيتون وسمسم. |
| **`LIGHT_MEAL_OR_SNACK`** | **15 دقيقة** | 12:30 ظهراً | **12:15 ظهراً** | 🥜 **سناك الشغل:** 2 موزة مهروسة مع زبدة فول سوداني + لب يقطين أبيض. |
| **`OUTSIDE_ORDER_MEAL`** | **60 دقيقة** | 04:30 عصراً | **03:30 عصراً** | 🍗 **الغداء الخارجي:** يُرسل التنبيه قبل مغادرة العمل بـ 30-45 دقيقة لطلب/شراء الوجبة وأنت مروح. |
| **`WORKOUT`** | **10 دقائق** | 06:15 مساءً | **06:05 مساءً** | 💪 **التمرين المنزلي:** ارتداء ملابس التمرين وتجهيز الدامبلز والحبل حسب جدول عضلات اليوم. |
| **`LIGHT_MEAL_OR_SNACK`** | **15 دقيقة** | 07:15 مساءً | **07:00 مساءً** | 🥤 **شيك الضخامة بعد التمرين:** لبن دافئ + شوفان مطحون + واي بروتين أيزوليت + كاكاو + عسل. |
| **`LIGHT_MEAL_OR_SNACK`** | **15 دقيقة** | 09:30 مساءً | **09:15 مساءً** | 🍽️ **العشاء ومكمل الحديد:** تونة أو بيض وبطاطس (ممنوع اللبن والجبن للامتصاص) + شراب الحديد وبرتقالة. |

## 📅 2. الجداول المتغيرة خلال الأسبوع (الأكل والتمارين)

### أ. جدول الغداء المتغير (الساعة 04:30 م | التنبيه 03:30 م):
* **السبت والثلاثاء:** وركين فراخ مشوية جاهزة منزوعة الجلد (250g) + 250g بطاطس مسلوقة/أرز + سلطة خضراء + قرص دايجستين.
* **الأحد والأربعاء:** 200g صدور فراخ مشوية جاهزة + 250g مكرونة مسلوقة بصلصة طماطم وزيت زيتون + قرص دايجستين.
* **الإثنين والخميس:** علبة تونة قطع مصفاة (أو وركين مشوي 250g) + 250g بطاطس/بطاطا مسلوقة + عيش بلدي + سلطة + قرص دايجستين.
* **الجمعة:** 200g لحم مشوي أو كفتة مشوية قليلة الدهن (أو فراخ) + 250g أرز/بطاطس + سلطة بزيت زيتون + قرص دايجستين.

### ب. جدول التمرين المتغير (الساعة 06:15 م | التنبيه 06:05 م):
* **السبت والثلاثاء (علوي دفع - Push Focus):** ضغط صدر بالدامبلز على الأرض + ضغط أكتاف بالدامبلز + تمرين ضغط + رفرفة جانبي + ترايسبس خلف الرأس.
* **الأحد والأربعاء (أرجل وبطن - Legs & Core):** سكوات بالدامبلز + ديدليفت روماني بالدامبلز + طعن (Lunges) + سمانة بالدامبلز + بلانك للبطن لمنع الكرش (3×45 ثانية).
* **الخميس (علوي سحب وظهر - Pull Focus):** عقلة باب بحبل المقاومة + سحب دامبل مفرد للظهر + فيس بول بحبل المقاومة + بايسبس تبادل + بايسبس شاكوش.
* **الإثنين والجمعة (راحة واستشفاء - Rest Days):** استشفاء عضلي وبدون حديد (يمكن المشي 20 دقيقة لتنشيط الهضم والشهية).

## 🎮 3. أوامر التحكم وإدارة الحالة (Start / Stop / Skip)

يمكنك التحكم بالنظام مباشرة من شات التيليجرام أو من خلال لوحة الويب:

1. **`ACTIVE` (مفعّل):**
   * الأمر: `/start` أو زر `[▶️ تشغيل التنبيهات]`
   * الحالة: النظام يرسل جميع التنبيهات اليومية في مواعيدها المحسوبة.
2. **`PAUSED` (متوقف مؤقتاً):**
   * الأمر: `/stop` أو زر `[⏸️ إيقاف مؤقت]`
   * الحالة: إيقاف التنبيهات لأجل غير مسمى حتى تضغط تشغيل مجدداً.
3. **`SKIPPED_TODAY` (إجازة اليوم):**
   * الأمر: `/skip_today` أو زر `[🏖️ إجازة اليوم]`
   * الحالة: يتوقف النظام عن إرسال باقي تنبيهات اليوم، و**يعود تلقائياً لوضع `ACTIVE` غداً الساعة 06:00 صباحاً** بتوقيت القاهرة.
4. **`جدول اليوم`:**
   * الأمر: `/today` أو زر `[📅 جدول اليوم]`
   * الحالة: يرسل لك البوت فوراً تقريراً مفصلاً بوجبات وتمارين اليوم الحالي.

## 🛠️ 4. هيكل المشروع (Project Structure)

```text
smart_fitness_notifier/
├── app.py                 # تطبيق FastAPI الرئيسي، تشغيل APScheduler، والواجهات البرمجية

├── schedule_data.py       # بيانات الـ 7 أيام، نصوص الوجبات بالعربي، وحسابات الـ Lead Time

│   └── index.html         # لوحة التحكم التفاعلية العصرية (Tailwind CSS + RTL)
├── requirements.txt       # الحزم والمكتبات المطلوبة
├── .env.example           # نموذج الإعدادات
├── .env                   # ملف الإعدادات الخاص بك (يحتوي التوكن)
├── Procfile               # للنشر السحابي على Render / Railway / Heroku
├── render.yaml            # مخطط النشر التلقائي على Render بنقرة واحدة

└── docker-compose.yml     # تشغيل فوري عبر Docker Compose
```

## 🚀 5. دليل الإعداد خطوة بخطوة في دقيقتين للمبتدئين

### الخطوة 1: استخراج توكن بوت التيليجرام (Telegram Bot Token)
1. افتح تطبيق تيليجرام على هاتفك وابحث عن: **`@BotFather`** (الذي يحمل علامة توثيق زرقاء).
2. اضغط **Start** ثم أرسل الأمر: `/newbot`.
3. سيطلب منك كتابة اسم للبوت (مثال: `My Fitness Coach`).
4. سيطلب منك كتابة معرف (Username) ينتهي بكلمة `bot` (مثال: `cairo_fitness_alert_bot`).
5. سيعطيك فوراً رسالة تحتوي على الـ **Token** بالشكل التالي:
   `7123456789:AAFlkjasd...`
6. انسخ هذا التوكن وافتحه في ملف `.env`:
   ```env
   TELEGRAM_BOT_TOKEN=7123456789:AAFlkjasd...
   ```
7. **الحصول على معرف الشات (Chat ID) تلقائياً:**
   * افتح البوت الذي أنشأته للتو واضغط **Start** (أو أرسل `/start`).
   * النظام سيقوم **تلقائياً بالتقاط الـ Chat ID الخاص بك وحفظه فوراً في `state.json`** دون الحاجة لكتابته يدوياً!
   * (أو يمكنك معرفته يدوياً بمراسلة `@userinfobot` وكتابته في `TELEGRAM_CHAT_ID`).

---

### الخطوة 2 (اختيارية): تفعيل واتساب عبر CallMeBot
إذا أردت وصول الإشعارات أيضاً على واتساب مجاناً:
1. احفظ رقم CallMeBot الرسمي أو افتح الرابط: `https://api.callmebot.com/whatsapp.php`
2. أرسل الرسالة التالية من رقمك في واتساب إلى الرقم `+34 941 01 99 61` (أو الرقم المعروض في الموقع):
   `I allow callmebot to send me messages`
3. سيصلك الـ `apikey` مجاناً في ثوانٍ.
4. ضع البيانات في ملف `.env`:
   ```env
   ENABLE_WHATSAPP=True
   CALLMEBOT_PHONE=+2010xxxxxxxx
   CALLMEBOT_API_KEY=123456
   ```

## 💻 6. التشغيل المحلي (على جهازك)

1. تأكد من وجود بايثون (Python 3.9+)، ثم افتح موجه الأوامر (Terminal / PowerShell) داخل مجلد المشروع:
   ```bash
   cd smart_fitness_notifier
   ```
2. تثبيت الحزم المطلوبة:
   ```bash
   pip install -r requirements.txt
   ```
3. تشغيل الخادم:
   ```bash
   python app.py
   ```
4. افتح المتصفح على:
   `http://localhost:8000`
   ستظهر لك لوحة التحكم مباشرة مع توقيت القاهرة الحي وعداد الإشعار القادم وإمكانية إرسال إشعار فحص تجريبي!

## ☁️ 7. النشر السحابي المجاني 24/7 (حتى يعمل والكمبيوتر مغلق)

لكي يعمل النظام على مدار الساعة ويرسل التنبيهات لهاتفك بدون الحاجة لترك جهاز الكمبيوتر قيد التشغيل:

### الخيار الأفضل والأسهل: النشر عبر **Render.com** (مجاناً 100%)
1. ارفع مجلد المشروع على حسابك في **GitHub** في مستودع خاص أو عام (Private/Public Repo).
2. سجل دخولك على موقع [Render.com](https://render.com) مجاناً بواسطة حساب GitHub.
3. اضغط على **New +** ثم اختر **Web Service**.
4. اختر المستودع الخاص بك (Repository).
5. سيقرأ موقع Render الإعدادات تلقائياً من ملف `render.yaml` أو املأ الخانات كالتالي:
   * **Runtime:** `Python 3`
   * **Build Command:** `pip install -r requirements.txt`
   * **Start Command:** `uvicorn app:app --host 0.0.0.0 --port $PORT`
   * **Instance Type:** `Free`
6. في قسم **Environment Variables** أضف:
   * `TIMEZONE` = `Africa/Cairo`
   * `TELEGRAM_BOT_TOKEN` = `التوكن_الخاص_بك`
   * `ENABLE_TELEGRAM` = `True`
7. اضغط **Deploy Web Service**.
8. في دقيقة واحدة سيصبح نظامك يعمل 24/7 سحابياً! وستحصل على رابط لوحة تحكم مجاني ومحمي بـ HTTPS.

> 💡 **ملاحظة للحفاظ على الخدمة مستيقظة:** الخطة المجانية في Render قد تنام عند عدم وجود زيارات للويب، لتفادي ذلك:
> يمكنك وضع رابط موقعك في خدمة فحص مجانية مثل [UptimeRobot.com](https://uptimerobot.com) ليقوم بزيارة الموقع كل 10 دقائق مجاناً، أو استخدام منصات أخرى مثل **Railway.app** أو **PythonAnywhere.com**.
